# Q-Control – Queue Management System

## Overview
A full-stack web application to manage queues efficiently with real-time updates and estimated waiting time.

## Tech Stack
- Frontend: React.js
- Backend: Node.js, Express
- Database: MongoDB

## Features
- Admin & User roles
- Real-time queue updates
- Estimated waiting time prediction

## How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/srilatha-0/Qontrol.git
cd Qontrol
```

### 2. Start the Backend

```bash
NOTE : before that at the project folder change the axoios call to the localhost of the port number as the modified it to host in the aws cloud platform

cd backend
npm install
node index.js
```

### 3. Start the Frontend (in a new terminal)

```bash
cd frontend
npm install
npm start
```

### 4. Open in Browser

```
http://localhost:3000
```
